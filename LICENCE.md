Where not otherwise stated, this project has an MIT licence.
Check an individual section of the project you want to use before assuming this licence applies. The zig compiler for example uses a non-standard licence.

- glad (glad.c, glad/glad.h): the generator is MIT. The code it generates is generally treated as public domain, but check the comment at the top of your generated files. 
- KHR/khrplatform.h: Khronos’s MIT-style licence, with the text in the file’s header.
- GLFW: zlib/libpng licence. Permissive, with no attribution required in binaries.
- libGL, libX11, libXrandr, libXi: MIT-style licences. The GPU driver (Mesa)
